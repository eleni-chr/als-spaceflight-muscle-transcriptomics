# Analysis of Muscle Transcriptomic Signatures in Spaceflight and Mechanical Unloading

Analysis code and documentation covering skeletal-muscle transcriptomic and proteomic analyses across ALS, spaceflight, mechanical unloading, recovery, exercise, and denervation.

## Manuscript

This repository contains the analysis and figure-generation code accompanying a manuscript submitted for publication.

## Data and execution

The public repository contains the R scripts and documentation; it does **not** redistribute the third-party input data. See [DATA_SOURCES.md](DATA_SOURCES.md) for each source accession, expected local input file or filename pattern, source link, and relevant citation guidance.

To reproduce the analyses, obtain the input files directly from their original repositories or publications, review the current terms for each source, and place the files at the paths or with the names listed in the manifest. Run the numbered scripts in sequence. Later figure scripts may require tables and workbooks produced by earlier analysis scripts; these intermediate files are generated by the workflow and are not source inputs.

Script 12 retrieves GEO sample metadata through GEOquery when a local cache is unavailable, so internet access is required for that step. Some annotation and pathway operations may also use online resources. Missing R packages may need to be installed.

The manifest documents provenance; it does not grant permission to redistribute third-party data. The Apache-2.0 license applies to the R code only.
